# ProyectoComercioElectronico

Curso Diseño De Patrones

Sistema De Comercio Electronico Para CompuX, desarrollado en el lenguaje de programacion Python.

Requisitos Del Sistema: 
Python versión 3.14, Entorno De Desarrollo Visual Studio Code.

Instrucción De Ejecución: 
Clonar el repositorio desde GitHub, abrir la terminal en la carpeta raíz del proyecto y ejecutar main.py. Siga las instrucciones en la consola.
